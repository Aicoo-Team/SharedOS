Q&A

How does it get the data?
From kernel audit events. The TrackRecordCollector wraps the AuditSink. Every authorization decision, every tool invocation is recorded by the kernel. We just index it.
What if an agent lies about its history?
It can't. Every field is derived from events the kernel wrote. The agent never reports its own behavior.
Does it add latency?
Near-zero. The collector is a passthrough sink — clones the event and adds it to a Map. Analysis is a pure function over that Map.
How do you handle large volumes?
StreamingTracker does incremental updates (no recomputation), or the persistent adapter lets you plug in SQLite/Postgres.
Can I customize the edge-probe formula?
Yes. Weights are tunable: 50% denial ratio, 30% retry-after-denial, 20% escalation rate. Adjust for your threat model.
Why is probe-agent's score only 0.33?
Only 8 tool calls. With more attempts and retries, the score climbs toward 1.0. The signal is denial ratio + retry pattern + escalation rate.
