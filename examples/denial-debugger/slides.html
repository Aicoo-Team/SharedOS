"Why Was I Denied?"

The SharedOS Denial Debugger

Four failures that look identical.
Four completely different diagnoses.

The Problem

Every SharedOS host hits this wall:

result.status: denied
result.error.code: tool_unavailable
result.error.message: The requested tool is not available

That's it. No explanation. No next step.

Four Gates

Every denial passes through one of four gates:

📋

Registration

Is the tool registered and its namespace enabled?

🔑

Capability Grant

Does a grant cover this actor, resource, action?

🏗️

Product Ceiling

Does host policy override the grant?

⚙️

Infrastructure

Did a wiring dependency fail?

The Solution

One function. Reads the audit trail. Tells you what went wrong.

import { diagnoseDenial } from "@aicoo/sharedos";

const result = await kernel.invokeTool(ctx, call);
if (result.status === "denied") {
  const diagnosis = diagnoseDenial(result, audit.events);
  console.log(diagnosis.nextStep);
}

Before: Without the Debugger

result.status: denied
result.error.code: tool_unavailable

...that's all you get.

After: Scenario 1

The tool doesn't exist.

Gate: 📋 registration
Code: tool_unavailable
Next step: registerTool() — the tool is not registered on this kernel

After: Scenario 2

The tool exists, but nobody gave you permission.

Gate: 🔑 capability_grant
Code: tool_unavailable
Next step: issue a grant covering this tool for this actor

After: Scenario 3

A grant existed, but product policy overrode it.

Gate: 🏗️ product_ceiling
Code: tool_unavailable
Next step: check the host's toolAccess.allowedTools policy

After: Scenario 4

The grant needs maxUses but the store isn't wired.

Gate: ⚙️ infrastructure
Code: tool_unavailable
Next step: wire a GrantUsageStore — this is a config problem, not permissions

Summary

Four failures. All look the same. None have the same cause.

  • Gate 1: Registration — Is the tool registered?
  • Gate 2: Capability — Does a grant cover this call?
  • Gate 3: Ceiling — Does host policy override it?
  • Gate 4: Infrastructure — Did a wiring dependency fail?

diagnoseDenial() reads the audit trail and tells you which one.

Get Started

// Already in the SDK — no extra install
import { diagnoseDenial } from "@aicoo/sharedos";

Or install standalone:

pnpm add @aicoo/sharedos-debugger
